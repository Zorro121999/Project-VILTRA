# Project-VILTRA

Prototype files in the ./*_proto folders

Delivery Code for Receiver and Transmitter is in
./transmitter_maker
./receiver_maker

Receiver can be directly flashed to Makerkit with Libero, the hex file for the MSS is already included in the flash.

For the transmitter first the bitstream has to be programmed to the Makerkit, then you have to use Softconsole and Run the programm on the Makerkit via the Debugger Interface.
